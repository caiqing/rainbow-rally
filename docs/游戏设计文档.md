## 1. 产品概述

| 项目 | 内容 |
|---|---|
| 游戏名（主推） | 《彩虹拉力队》 Rainbow Rally |
| 备选名 | 《希望拉力队 Hope Rally》《嘟嘟救援拉力》《彩虹引擎 Rainbow Garage》 |
| 类型 | 横屏横版自动前进赛车（跑酷式驾驶）+ 收集养成 + 车库拼装 |
| 平台 | 浏览器（桌面 + 手机横屏），纯前端，双击即玩，可离线 |
| 目标玩家 | 4~12 岁儿童及其家长（亲子同玩） |
| 核心体验 | 开着"自己拼的车"穿越多彩世界，靠技巧收集与治愈（而非战斗）过关 |
| 技术基调 | HTML5 Canvas + 原生 JS，零依赖零外部素材，WebAudio 合成音效，localStorage 存档（对齐工作区 stickman-arena / q-jet-raid 惯例） |

### 1.1 三条硬约束（家长的验收标准）

1. **不恐怖**：没有死亡、血腥、鬼怪。敌人是被"灰灰雾"弄脏心情的小动物/小机器，被治愈后恢复彩色、开心跳走。失败 = 车子"呼呼大睡"，检查点复活。
2. **不太难**：自动油门，玩家只管上下移动 + 跳跃 + 氮气；五档难度（亲子/轻松/标准/挑战/专家）+ AI 代驾托管；撞击只掉心心减速，永不重头再来。
3. **画面精美**：糖果废土风（详见第 8 节美术指南）——末日但温暖，全圆角、大眼睛、粗描边，点亮小站后世界真的会一块块变彩色。

## 2. 故事与世界

### 2.1 世界观

世界本来五彩缤纷。大发明家**呼噜噜**造了一台"万能涂色机"，他想给全世界刷上自己最喜欢的灰色（他觉得灰色最酷，但没人陪他商量）。结果涂色机打了个大喷嚏，喷出漫天**灰灰雾**——

- 花草蔫了，风车停了，摩天轮歪了；
- 小伙伴们的机器宠物被雾罩住，睡着变成了**灰灰怪**；
- 只有一座座老式加油站还亮着灯，人们叫它们**彩虹小站**。

山谷车库里的孩子们决定：组建**彩虹拉力队**，开着爷爷留下的拼装赛车出发——每点亮一座小站，附近的土地就恢复一块颜色。等开到呼噜噜的要塞，要用世界上最大的喇叭告诉他：**世界喜欢的颜色，要大家自己选！**

### 2.2 主线结构（6 大区域 · 18 条赛道 · 6 场 Boss 挑战赛）

每区域 3 条赛道 + 1 场"呼噜噜的挑战赛"（Boss 战）：

| 章 | 区域 | 地形特色 | 新玩法教学 | Boss 挑战赛 |
|---|---|---|---|---|
| 1 | 奶油沙漠 | 平坦沙丘、仙人球、旧轮胎堆 | 基础驾驶：移动/跳/氮气 | 挑战赛：追上呼噜噜的试作车（输了不扣分，重试免费） |
| 2 | 蘑菇废墟森林 | 绕枯树、弹跳蘑菇、倒塌电线杆 | 弹跳蘑菇连跳、撞木箱 | 雾雾吐吐机群：限时关掉 5 台吐雾机 |
| 3 | 叮当河谷 | 河流、断桥、水车废墟 | 换浮筒轮渡河、水下收集 | 渡河竞速：护送运彩色的木筏过三段河 |
| 4 | 风车雪山 | 长上坡、冰面打滑、雪堆 | 雪橇轮、爬坡耗速与滑降加速 | 雪山追逐：躲开呼噜噜扔的棉花糖炸弹 |
| 5 | 彩虹峡谷 | 大断桥、峡谷风、滑坡 | 抓钩钩柱飞跃、滑坡漂移 | 峡谷大飞跃：借助所有跳台完成超远跳跃 |
| 6 | 呼噜噜要塞 | 齿轮机关城、彩色谜题路 | 综合考验 | 最终战：不是打败他——和铁蛋一起在比赛里追上他、把蛋糕和礼物送到他车上 |

**结局**：铁蛋（队里的机器人，正是呼噜噜早年造的家用机器人）把大家收集的"七彩齿轮"装回涂色机，机器被改装成**彩虹喷泉**，世界恢复色彩。呼噜噜红着脸道歉，加入车库当修车师傅——

> **他开的"呼噜噜修理铺"就是未来商店系统的入口（第 7 节）。反派洗白后成为商店老板，玩法与叙事天然衔接。**

### 2.3 情感设计要点

- **治愈而非消灭**：用水炮/喇叭"治愈"灰灰怪是加分项，撞飞它只得基础分。鼓励善良，不鼓励暴力。
- **世界可视化恢复**：区域地图初始是褪色暖灰，每点亮一座小站，对应区块渲染为彩色——进度即奖励。
- **角色有牵挂**：朵朵想找回自己的花园、铁蛋想找到造自己的人（呼噜噜）、皮皮要给车库全员摘果子。过场用对话泡泡（3~4 句以内），不写长文本。
- **没有坏人**：呼噜噜只是寂寞又固执的发明家，结局全员和解。适合全家讨论。

## 3. 核心玩法

### 3.1 单局循环（一条赛道 90~150 秒）

```
出发 → 自动加速前进 → 上下移动/跳跃/氮气
 → 躲障碍、治灰灰怪、收齿轮币与阳光罐头 → 经过地形机关（坡/河/断桥）
 → 抵达小站点亮它（过场小烟花） → 结算：星级（收集率+受击数）+ 齿轮币
 → 回车库：拼车/换人/换装备 → 下一关
```

### 3.2 操作

| 输入 | 动作 |
|---|---|
| ↑↓ / W S / 触屏上下拖动 | 上下移动 |
| 空格 / 右下大按钮 | 跳跃（长按跳更高） |
| Shift / 右下大按钮 | 氮气冲刺（消耗阳光罐头能量条） |
| E / 左下小按钮 | 使用装备（水炮/喇叭/抓钩） |
| 桌面：P 暂停 · M 静音 | 同 q-jet-raid 惯例 |

### 3.3 容错设计（儿童向关键决策）

- **撞击** = 嘭→星星粒子→掉 1 颗心 + 减速 2 秒 + 2 秒无敌闪烁。
- **心心归零** = 车子停在路边"呼呼大睡"，头顶冒 Zzz，3 秒后从检查点复活，**已收集物品不丢失**。
- **掉河里** = 自动被"救援气球"捞回路面，只损失 1 心。
- **关卡内设 2 个检查点**；任何失败不返回主菜单。
- **AI 代驾**：任何难度下可托管，AI 自动躲障、治怪、收币（沿用云朵突击队已验证的模式）。

### 3.4 五档难度

| 难度 | 障碍密度 | 敌人速度 | 备注 |
|---|---|---|---|
| 亲子 | 极稀疏，自带常驻护盾 | 慢 | 家长陪玩/幼儿独立玩 |
| 轻松 | 稀疏 | 慢 | |
| 标准 | 中 | 中 | 结算满星基准 |
| 挑战 | 密 | 快 | 额外齿轮币 +20% |
| 专家 | 很密 | 快 | 额外齿轮币 +50%，限定无敌时间缩短 |

### 3.5 障碍与"敌人"清单

**被动障碍**：歪路障（会叹气）、轮胎堆、木箱（可撞碎，掉齿轮）、倒塌电线杆、仙人球、雪堆、齿轮闸门（收集连击解锁）。

**地形机关**：弹跳蘑菇、滑坡（自动加速，爽点）、断桥（跳/抓钩）、渡河（浮筒轮）、隧道（内有小星星引导，不黑屏吓人）、齿轮桥（连续收集会自动铺桥）。

**灰灰怪（全部可治愈，治愈后送 3 齿轮币 + 彩色小烟花）**：

| 名称 | 行为 | 应对 |
|---|---|---|
| 灰灰喵 | 在路中间打滚 | 水炮治愈；撞上只减速不掉心 |
| 灰灰球球 | 滚动的"刺球"（睡着的刺猬） | 跳过或氮气冲过 |
| 雾雾吐吐机 | 停在路旁吐灰雾，雾会挡视线 | 水炮关机 = 短暂全屏彩色波（清屏） |
| 大块头邦邦 | 区域小 Boss，拦路 | 喇叭震它转圈即让路，还会挥手 |

### 3.6 收集物与资源

- **齿轮币**（软通货）：路上成串摆放，鼓励走线。
- **阳光罐头**：充能氮气条；成套收集（每关 3 个隐藏罐头） = 星级加成。
- **七彩齿轮**（章节信物）：每关 1 枚，藏在支线路/高风险高奖励处，点亮小站的钥匙，也是终局剧情道具。

## 4. 车辆拼装系统（需求 1a）

### 4.1 槽位模型（积木式拖放）

```
[尾部配件]  [车顶配件]
[前部配件]  [底盘·驾驶舱(坐驾驶员)]  ←— 车库场景拖放拼装
   [轮子×2区]   [引擎]
```

| 槽位 | 部件示例 | 影响属性 |
|---|---|---|
| 底盘 | 小皮卡（均衡）/ 巴士头（多 1 心、略慢）/ 越野卡丁（快、脆） | 速度/心数/外观主体 |
| 轮子 | 圆轮胎 / 大越野胎（山地抓地）/ 水浮筒（渡河）/ 雪橇板（雪地） | 地形适应性（第 3.5 节机关对应） |
| 引擎 | 嘟嘟引擎 → 嗖嗖引擎 → 轰隆隆引擎 | 最高速度与氮气强度 |
| 车顶 | 信号旗（+金币 10%）/ 小风车（+阳光收集半径）/ 备胎（+1 心） | 小加成 + 可爱外观 |
| 前部 | 水炮（治灰灰怪）/ 犁刀（撞碎木箱类障碍）/ 抓钩（峡谷钩柱） | 装备功能位 |
| 尾部 | 推进器（氮气时长 +50%）/ 备用油箱（能量上限 +1） | 能量相关 |

### 4.2 拼装体验

- 车库场景内**拖放**部件到车体轮廓；已装部件实时反映属性条（速度/抓地/浮力/心心四维）。
- 拼装完成播放小动画：扳手敲两下 + 车灯眨眼 + 喇叭"叭叭"。
- 提供 3 套**推荐方案**一键穿搭（越野型/渡河型/竞速型），避免低龄玩家选择困难；进入新章节时推荐对应轮子但不强制（普通轮渡河只是变慢，不会死）。
- 车辆渲染为参数化组合绘制（底盘×轮子×配件独立素材位），拼什么画什么。

## 5. 驾驶员系统（需求 1b）

5 名队员，外观直接画在驾驶舱车窗里（孩子随时能看到"谁在开车"，增强情感连接）：

| 队员 | 人设 | 被动技能 |
|---|---|---|
| 阳阳（队长，10 岁） | 热血、戴红色头盔 | 「冲呀」开局 3 秒免撞 + 起步加速 |
| 朵朵（9 岁，植物爱好者） | 温柔、别着向日葵发卡 | 「拾光」收集半径 +50%，磁铁效果 |
| 铁蛋（家用机器人） | 憨厚，是呼噜噜造的 | 「铁布衫」心心上限 +1，泥地/灰雾不减速（剧情核心：最终由他说服呼噜噜） |
| 花花奶奶（车库工程师） | 慈祥、口袋全是工具 | 「巧手」装备冷却 −40%，被撞掉的心心每 30 秒自动回 1 |
| 皮皮（机器小猴） | 调皮、挂在车顶棚 | 「蹦蹦」跳跃高度 +20%，空中收集翻倍 |

规则：每关自由更换队员，无锁定；驾驶员技能是"风味加成"而非"必需配置"——保证换谁都能通关（儿童公平性）。

## 6. 装备系统（需求 1c）

| 装备 | 类型 | 效果 | 冷却 |
|---|---|---|---|
| 泡泡护盾 | 被动 | 抵消 1 次撞击，30 秒自动回充 | — |
| 大喇叭 | 主动 | 震退/唤醒前方灰灰怪与邦邦 | 8 秒 |
| 水炮 | 主动 | 治愈灰灰怪 / 关闭吐雾机（核心善良玩法） | 3 秒 |
| 抓钩 | 主动 | 在峡谷关卡钩柱飞跃走捷径 | 按关卡出现 |
| 备用油箱 | 被动 | 能量上限 +1 格 | — |

- 装备位 = 前部 + 尾部 + 车顶各 1，即一辆车最多 3 件，拼装系统统一承载。
- 装备获取：章节通关解锁 + 商店购买（第 7 节）。

## 7. 商店与经济（需求 3 · 未来规划 M3）

**商店入口即剧情角色**：呼噜噜洗白后经营"呼噜噜修理铺"，基地车库旁的小房子，结局后解锁。

### 7.1 货币

| 货币 | 来源 | 用途 |
|---|---|---|
| 齿轮币 | 跑道收集 + 结算奖励 + 每日订单 | 部件/装备/涂装 |
| 彩虹星 | 关卡星级（S/A/B）与成就 | 稀有部件、车库装饰、角色服装 |

### 7.2 货架分区

1. 轮子与引擎（成长向，部分仅星币）
2. 前后装备（功能向）
3. 涂装与贴纸（纯外观：向日葵黄/西瓜红/薄荷绿… + 色板自选，支持亲子一起调色）
4. 车库装饰（基地小彩旗、地毯、奖杯柜）

### 7.3 经济原则（家长关怀，写进设计红线）

- **无内购、无广告、无抽卡**：全部内容用游戏内货币获得；星币只来自游玩成就。
- 商店定价让"普通游玩 2~3 小时"可解锁大部分功能件；外观件拉长收集线。
- 每日订单（"把 3 罐阳光送去山那头奶奶家"）给小额齿轮币，鼓励每天开一小局，但**不做连续签到惩罚**（断签无损失）。

## 8. 美术与音效方向

### 8.1 美术关键词：糖果废土（Candy Wasteland）

- **末日但温暖**：褪色区域用**暖灰奶油色**（绝不用冷灰/黑紫），点缀歪掉的摩天轮、大齿轮风车、笑脸路障——废墟元素全部萌化。
- **色彩即进度**：地图与关卡背景按"点亮进度"从暖灰向糖果色渐变（向日葵黄、薄荷绿、西瓜红、天空蓝），第 N 章引入 1 个新主色。
- **造型规范**：全圆角、2.5 头身角色、车高 ≈ 轮高 ×2、粗描边、大眼睛；天空常挂一缕彩虹。
- **视差背景 4 层**：远山 → 中景可爱废墟剪影 → 近景植被/机关 → 路面，MVP 用 Canvas 程序化绘制（零素材惯例）；后续里程碑可用 AI 生成插画升级过场/图标/宣传图（工作区已有 image-01 生成管线可复用）。

### 8.2 音效（WebAudio 全合成）

- 引擎声随速度变频的"嘟嘟嘟"；氮气"咻——"；治愈"叮铃"上行琶音；撞击"嘭+星星"；点亮小站小段胜利旋律。
- BGM 明快圆舞曲/进行曲风，Boss 战也是"欢快追逐曲"而非紧张压迫曲。
- 首次交互后才启动音频（浏览器策略，沿用现有项目做法）。

## 9. 技术方案

| 项 | 方案 |
|---|---|
| 渲染 | HTML5 Canvas 2D + requestAnimationFrame，固定时间步进 |
| 物理 | 自写轻量 2D：重力、坡度斜面、水面浮力判定、AABB 碰撞；不引入引擎库 |

| 存档 | localStorage：车库配置、货币、关卡星级、难度偏好、点亮进度 |
| 代码结构 | 参考 sanguo-kill 模块化：`js/engine.js / data.js / player.js / track.js / ui.js / fx.js / audio.js / main.js` |
| 部署 | GitHub Pages + WorkBuddy 试玩链接（现有流程） |

## 11. 风险与开放问题

1. **"赛车感"手感**：自动前进 + 自由上下移动能否给出"开车"而非"跑酷"的感觉——M0 优先验证；备选方案是三车道制（更简单但驾驶感弱）。
2. **地形物理调参**：坡度、跳跃抛物线、浮筒浮力需要较多迭代，建议 M0 就把坡道和水面做进原型。
3. **18 条关卡的制作成本**：用"地形分段模板 + 程序化变体"降低手作量；先做满 1 章 3 关再批量复制。
4. **单局时长**：儿童注意力约 2~3 分钟，关卡控制在 150 秒内，宁可多关卡。
5. **命名待定**：主推《彩虹拉力队 Rainbow Rally》，与家长确认后再定目录名是否沿用 `rainbow-rally`。
