# 彩虹拉力队 Rainbow Rally

一个横屏 Q 版亲子赛车游戏：世界失去了颜色，孩子们开着自拼的赛车穿越奶油沙漠，点亮一座座彩虹小站，把颜色送回世界每个角落。

纯前端（HTML5 Canvas + 原生 JavaScript，零依赖、零外部素材）编写，双击即玩，可离线运行。音效与 BGM 由 WebAudio 实时合成。

> 📖 完整设计文档：[docs/游戏设计文档.md](docs/游戏设计文档.md)
>
> 当前进度：**M0 手感原型**（奶油沙漠单赛道）

## 玩法特色

- 🚗 **自动前进的横版赛车**：只管上下移动、跳跃、氮气，专注躲避与收集
- 😺 **治愈而非战斗**：跳过灰灰喵的头顶就能治愈它（送齿轮币），撞到它也不会受伤
- 💖 **没有 Game Over**：撞障碍只掉一颗心；心心用完车车睡一觉，检查点满血复活，收集不丢失
- 🪙 **三线收集**：齿轮币（财富）、阳光罐头（氮气能量 + 星级）、七彩齿轮（每关 1 枚彩蛋）
- 🍼 **三档难度**：亲子护航（护盾常开）/ 标准速度 / 专家冲刺（齿轮币 +50%）
- 🏁 **星级结算**：S / A / B 评价 + 彩虹币累计（为后续车库拼装与商店做准备）
- 📱 **双输入**：桌面键盘 + 手机触屏（拖动移动 + 大按钮），竖屏时提示横屏

## 操作

| 输入 | 动作 |
|---|---|
| ↑ ↓ 或 W S（触屏：拖动屏幕） | 上下移动 |
| 空格 / J（触屏：右侧大按钮） | 跳跃（长按跳更高） |
| Shift / L（触屏：绿色按钮） | 氮气（消耗阳光能量条） |
| P / Esc | 暂停 |
| M | 静音 |

## 开始游戏

- **方式一**：直接双击 `index.html` 用浏览器打开
- **方式二**（本地服务器）：

```bash
python3 -m http.server 8130
```

然后访问 <http://localhost:8130/>。

| 罐头塔 | 叠轮胎高台，跳上塔顶收阳光罐头 |

## 技术说明

- 渲染：Canvas 2D，1280×720 逻辑分辨率 letterbox 适配，DPR 缩放
- 物理：自写轻量 2D（重力跳跃 / AABB + 高度轴碰撞），无引擎依赖
- 关卡：模式化程序生成（`js/track.js`），难度控制密度与速度
- 音频：WebAudio 全合成（引擎随速变频、BGM 琶音、13 种音效）
- 存档：localStorage（彩虹币累计 / 单局最高 / 难度与静音偏好）
- 代码结构：`data / audio / track / entities / game / ui / main` 七模块
- 测试：`node test/smoke.js` —— Node 环境跑通"撞击→睡觉→复活→通关结算"全链路、三难度三种子赛道生成校验、内置简单 AI（AI 代驾雏形）验证关卡可达性
